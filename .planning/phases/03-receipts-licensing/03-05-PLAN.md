## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| publisher -> runtime | The license is a publisher-signed token verified offline; a token for another lease or outside the skew window must be rejected. |
| library -> error path | paseto exceptions must not leak token/secret material into any Result/log. |
| supply chain | paseto is a three-week-old rewrite (SUS/too-new); its install is gated. |
