## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| store -> verifier | A persisted chain (Phase 6) is untrusted at read time; verifyChain must detect tampering without trusting any stored hash. |
| entry-writer -> receipt | Caller-supplied entry input must not carry secrets into the audit trail. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | chain.ts hash linkage | high | mitigate | Recompute-on-verify via the single @stint/spec canonicalize/hashCanonical; the golden vector pins bytes so cross-platform drift is caught. |
| T-03-02 | Information Disclosure | ReceiptEntryInput type | high | mitigate | Writer input type carries only argsHash + redactedSummary + typed non-secret fields; raw args/tokens/license are a compile error to include (D-16). |
| T-03-03 | Repudiation | spec/ALP.md section 11 | medium | mitigate | Normative entry format + golden conformance vector make the audit trail reproducible by any implementer. |
</threat_model>
