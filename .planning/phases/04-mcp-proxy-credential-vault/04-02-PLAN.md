<objective>
Prove the whole Phase 4 enforcement path end-to-end with one thin vertical slice: an agent connects over MCP to a per-lease `Server`, `tools/list` shows only the tools its lease permits, and a `tools/call` on a permitted `read` tool flows through the runtime-owned binding → pure `evaluatePolicy` → an injected execute stage → and leaves exactly one verified-chain receipt — all serialized per lease. This establishes `catalog.ts`, `server.ts`, `dispatch.ts`, the lease-serializer wrapper, and `call-receipt.ts` with clean injected seams (`ExecuteStage`, `ApprovalStage`, `CapEnforcer`) that plans 04-03/04-04/04-05 fill in without editing the dispatch.

Purpose: catch any architectural dead-end (SDK `Server` wiring, JSON-Schema `tools/list`, per-lease transaction shape, secretless receipt) on the first commit, before ten layers are built on it.
Output: a production-quality tracer covering PRXY-01 and RCPT-01 for one permitted tool and one denied tool.
</objective>
