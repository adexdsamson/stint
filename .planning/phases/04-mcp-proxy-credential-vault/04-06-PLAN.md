<objective>
Supply 04-02's injected `ExecuteStage` with the real vault-backed outbound path: resolve the OAuth access token from the 04-05 vault, hand it to the trusted `OutboundConnector` port (which attaches it and makes the call), and wrap the whole port call in a narrow credential scrubber so no token — and never the publisher license — can cross the agent-facing boundary in a response, an error, or a receipt (PRXY-06, LIC-05, D-01, D-02).

Purpose: this is the injection-without-exposure call site the whole phase's secretless claim rests on; the adversarial tests aim a token-echoing/throwing port at the agent boundary and prove nothing leaks.
Output: `connectors/outbound-connector.ts` (port + reference REST impl), `vault/scrub.ts`, `vault/execute-stage.ts`, and the two secretless adversarial suites.
</objective>
