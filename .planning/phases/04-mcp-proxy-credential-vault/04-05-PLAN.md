<objective>
Build the credential vault's refresh hot path (D-03, D-04): a narrow seed seam, a secretless module-private token store keyed `leaseId:resource`, per-call expiry against the injected clock, a real `oauth4webapi` refresh-token grant carrying the RFC 8707 `resource` indicator, and — the PRXY-08 crux — per-credential single-flight refresh proven by counting actual token-endpoint hits against `oauth2-mock-server`. The refresh path also emits the `provider_revoked` vs `transient_error` classification 04-07 consumes.

Purpose: this is the vault foundation 04-06's injection stage and 04-07's revocation detection both build on; it is where "never two redemptions of one refresh token" is made true and tested honestly (the mock has no native reuse-detection).
Output: `vault/oauth-client.ts`, `vault/credential-vault.ts`, the mock-AS test harness, and the single-flight proof.
</objective>
