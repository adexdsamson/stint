<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| manifest file -> runtime | an untrusted or tampered manifest must never reach consent or activation. |
| runtime private key -> disk | the Ed25519 signing key is persisted and must not leak into logs. |
| credentials file -> vault | secret tokens enter memory only, never the store/receipts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-12 | Spoofing / Tampering | manifest signature | high | mitigate | `verifyEnvelope(trustStore)` before consent; untrusted publisher/kid fails closed with EXIT_CODES.manifestInvalid; size cap on parse. |
| T-06-13 | Info disclosure | runtime private key on disk / in logs | high | mitigate | 0600 where honored; key bytes never logged; fixed error messages (§14). |
| T-06-14 | Elevation of privilege | consent timeout | high | mitigate | `awaitConsentDecision` core-owns timeout->decline; create defaults to decline on any non-grant. |
| T-06-15 | Info disclosure | error text leaking upstream detail | medium | mitigate | CliError fixed messages; `{error,code}` under --json; no jose/verify message or stack printed. |
</threat_model>
