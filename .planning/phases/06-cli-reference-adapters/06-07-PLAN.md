<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user CLI action -> irreversible teardown | revoke/cleanup drive destructive, largely one-way lease endings. |
| credentials file -> teardown vault | OAuth tokens seed the vault so revoke_oauth is honest; never persisted. |
| on-disk lease state -> teardown eligibility | a lease's state gates which teardown path is legal (idempotent resume). |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-23 | Repudiation | dishonest revoke_oauth receipt | high | mitigate | build TeardownDeps with a REAL vault seeded from --credentials; never the happy-path placeholder (Anti-Pattern, Open Q5). |
| T-06-24 | Tampering (integrity) | non-idempotent retry re-running steps | high | mitigate | retryTeardown resumes via recorded step outcomes; test asserts succeeded steps are not re-run and the lease never returns to active (Phase 5 D-15/D-17/D-23). |
| T-06-25 | Elevation of privilege | agent-driven ending | high | mitigate | revoke actor is `user` only; illegal source states refused with EXIT_CODES.wrongState; the agent is never an actor for ending a lease. |
| T-06-26 | Info disclosure | credential-file contents persisted/printed | high | mitigate | credentials held only in the in-memory vault; never written to store/receipts or printed. |
</threat_model>
