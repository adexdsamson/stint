<objective>
Build the reference terminal `HostAdapter` (HOST-02) and its render primitives entirely outside `@stint/core` — proving the published four-method `HostAdapter` contract is implementable by a plug-in. The adapter only ever renders and proposes; core owns every deny-by-default outcome (D-05), so a hang, error, EOF, or missing TTY can never become an approve/grant/confirm.

Purpose: this is one of the phase's two "proof by implementation" deliverables. It is unit-testable in isolation (faked TTY streams) before any CLI command wires it in (06-04 create, 06-06 run).
Output: `createTerminalHostAdapter`, `sanitizeForTerminal`, `createColors`-based `style.ts`, `askLine` prompt with countdown, and `renderConsent`.
</objective>
