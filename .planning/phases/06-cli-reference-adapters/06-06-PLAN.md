<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent (MCP client) -> proxy | the agent can only see/call what the lease permits; approvals are out of band. |
| stdio channel <-> human terminal | stdin/stdout are the MCP channel; human prompts must use a separate controlling terminal. |
| credentials file -> vault | OAuth tokens seed the in-memory vault only, never the store/receipts/agent. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-19 | Elevation of privilege | approval via no-TTY/hung adapter during run | critical | mitigate | adapter denies with no TTY; core's awaitApprovalDecision folds to deny:timeout; no-TTY smoke test asserts deny (Pitfall 4/D-05). |
| T-06-20 | Tampering (protocol) | human bytes on the MCP stdout channel | high | mitigate | no stdout writes on the run path; human output to stderr/controlling terminal; stdio smoke asserts a clean handshake. |
| T-06-21 | Info disclosure | OAuth/license leaking to the agent | high | mitigate | reuse `createVaultExecuteStage` (secretless boundary, LIC-05/PRXY-06 already tested); credentials never persisted. |
| T-06-22 | DoS | lock held across approval wait blocks another terminal | medium | accept | documented; contending command surfaces LeaseBusyError + EXIT_CODES.leaseBusy (Pitfall 5). |
</threat_model>
