<objective>
Deliver the enabling `LeaseStore` contract in `@stint/core` — an async CRUD interface plus a serialized read-modify-write primitive (`transaction`, a.k.a. `withLease`) that carries the per-lease serialization ALP.md §9 requires (D-13) — with an in-memory test double and a reusable, shareable contract-test factory exported from a new `@stint/core/testing` subpath (D-14), so the Phase 4 proxy and Phase 5 teardown have a store to depend on and the Phase 6 JSON-file store can run the identical suite and cannot drift. This plan also wires the complete `@stint/core` public API surface: the barrel export of every Phase 2 symbol (HOST-01 exports the HostAdapter and LeaseStore contracts platform builders implement), the `./testing` package export, and the tsdown second entry.

Purpose: the LeaseStore is the concurrency-safety boundary for the whole runtime; putting the serialization requirement in the contract (and proving it once with a reusable suite) means every store implementation, present and future, is held to the same no-lost-updates guarantee. This is the last plan in the phase and makes the whole package build, typecheck, lint, and test green.
Output: `lease-store.ts`, `testing.ts`, the finished `index.ts`/`package.json`/`tsdown.config.ts`, and the contract + public-API tests.

Note: `packages/core/src/lease-store.ts` has no async I/O analog in the tracked codebase (see 02-PATTERNS "No Analog Found"); use `verifyEnvelope`'s async-Result shape as the structural precedent and design the per-id promise-chain serialization directly from D-13.
</objective>
