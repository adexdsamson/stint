| runtime -> mock services | access token attached here; license must never appear |
| runtime <-> mock publisher | license issue/verify + cleanup bearer verification |
| headless user-agent -> mock AS | PKCE + state protect the code grant |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-LIC | Information disclosure | services recorder | high | mitigate | `assertNoLicenseLeak` fails on any `v4.public.` substring in service requests (LIC-05). |
| T-07-REPLAY | Replay | publisher /alp/cleanup | high | mitigate | `verifyCleanupToken` + single-use jti (409 on replay), scope-bound to `cleanup:<lease_id>` (spec §10). |
| T-07-CSRF | Tampering | oauth acquire | medium | mitigate | PKCE verifier + `state` validated by `validateAuthResponse` (RFC 9207). |
| T-07-TESTLEAK | Tampering | fixture imports | medium | mitigate | Fixtures import `@stint/core/license-issuer`, never `@stint/core/testing` (no vitest at runtime, Pitfall 5). |
| T-07-INSECURE | Information disclosure | acquire allowInsecureRequests | medium | mitigate | Insecure flag set only against the loopback mock AS (localhost), with the eslint-disable scoped comment. |
| T-07-SC | Tampering | npm deps | low | accept | No new package (pre-existing pins). |
