<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent -> proxy | ungranted/denied calls must never reach a service |
| user revoke (separate actor) -> teardown | user-actor revoke auto-chains teardown; agent can never revoke |
| retry -> teardown orchestrator | idempotent resume must not re-run succeeded steps |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-SCOPE | Elevation of privilege | out-of-scope call | high | mitigate | Ungranted `pay`-class tool hidden from tools/list, denies `no_binding`, zero service hits, denied receipt (PRXY-02/03). |
| T-07-APPROVAL | Spoofing | approval path | high | mitigate | Approve/deny/timeout only via HostAdapter; denied/timed-out calls make no service hit (PRXY-05). |
| T-07-REPLAY | Replay | cleanup retry jti | high | mitigate | Two distinct jtis across attempts; succeeded steps not re-run (TEAR-04). |
| T-07-STALE | Tampering | post-revoke call | medium | mitigate | A revoked/torn-down lease denies `lease_not_active`; lease never returns to active. |
| T-07-SC | Tampering | npm deps | low | accept | No new package (pre-existing pins). |
</threat_model>
