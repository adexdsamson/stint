<objective>
Turn `runLease` into the single composition point the in-process harness and the spawned `stint run` share (Pattern 4): identifier-to-endpoint fetch mapping (D-06/Pitfall 3), loopback-derived vault insecure flag (Pitfall 2), real `teardownSteps` (Pattern 3/Pitfall 8), in-memory license custody with best-effort per-call refresh (D-07/D-17, LIC-03/05), and an additive host-side `RunningLease.verifyOutcome()` (D-15) that drives the manifest's `resource_query` verifier to `completed`; then export `runLease`/`createRealDeps` from `@stint/cli`.

Purpose: the shipped run path never sets `allowInsecureRequests`, passes no `teardownSteps`, has no license custody/refresh, uses the binding resource identifier as the request URL, and has no completion trigger. These are the remaining gaps that make a hybrid lease work end-to-end and reach `cleaned_up` via its verifier (LIFE-06). Depends on plan 07-03's loopback helper, publisher binding and license-issuer client wiring.
Output: the extended `runLease`/`RunningLease`/`RunLeaseOptions`, the optional profile `endpoints` map, the threaded `run.ts`, the barrel exports, and scoped tests for the hybrid outbound path, refresh clamp, and verifier completion.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| proxy execute stage -> outbound connector | the only place a token is attached; the license must never cross here |
| host caller -> verifyOutcome | runtime-run completion; the agent's MCP channel must never reach it |
| runLease -> authorization server | refresh over loopback http requires the derived insecure flag |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-LIC | Information disclosure | ExecuteStage license custody | high | mitigate | Custody is read only for refresh; the connector credential stays `{ accessToken }` — license never forwarded to a customer resource (LIC-05); asserted in test. |
| T-07-COMPLETE | Elevation of privilege | verifyOutcome | high | mitigate | Host-side method, never registered as an MCP tool; `tools/list` exposes no completion tool; the agent's calls can never complete the lease (D-15, Phase 5 D-03). |
| T-07-CLOCK | Tampering | per-call reissue clamp | high | mitigate | `clampedLicenseExpiry` clamps reissue to `lease.expiresAt`; no reissued exp exceeds it (LIC-03); null reissue is best-effort no-op (D-17). |
| T-07-INSECURE | Information disclosure | runLease vault flag | high | mitigate | `allowInsecureRequests` derived via `isLoopbackHttp(profile token endpoint)` only. |
| T-07-URLMAP | Tampering | endpoints fetch wrapper | medium | mitigate | endpoints values validated https-or-loopback at profile parse; unmapped identifiers pass through unchanged. |
| T-07-SC | Tampering | npm deps | low | accept | No new package (pre-existing pins). |
</threat_model>
