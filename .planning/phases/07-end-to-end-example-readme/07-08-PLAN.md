<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host launcher -> spawned stint run | stdio pipes; console visibility governs where the approval prompt renders |
| spawned bin stdout -> agent client | stdout is the MCP channel — must carry only protocol bytes |
| quickstart stdout -> user | the printed success signal must never contain a secret |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-CONSOLE | Elevation of privilege | launcher windowsHide | high | mitigate | Hard-coded `windowsHide:false`/`shell:false`; spy-spawn guard fails on drift; hidden console denies by timeout (fail-safe, D-08/D-09). |
| T-07-SECRETS | Information disclosure | bin stdout / quickstart output | high | mitigate | Smoke + quickstart scan for access-token/`v4.public.` substrings; `stint run` never writes to stdout except protocol bytes. |
| T-07-NONINT | Denial of service (silent deny) | quickstart non-TTY | medium | mitigate | Non-TTY auto-grant + short approvals timeout so the verbatim command completes deterministically (Pitfall 9). |
| T-07-BIN | Tampering | bin resolution | low | mitigate | Resolve via `import.meta.resolve("@stint/cli")` sibling, not `node_modules/.bin` (Pattern 7); existsSync guard. |
| T-07-SC | Tampering | npm deps | low | accept | No new package (pre-existing pins). |
</threat_model>
