<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent (MCP Client) -> proxy | untrusted tool calls; results/errors must be secret-free |
| runtime -> services / publisher | token attaches at the connector only; license stays in custody |
| host caller -> verifyOutcome | completion is runtime-run, never agent-reachable |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-SECRETS | Information disclosure | agent-visible results + receipts | high | mitigate | Substring scan asserts no access token / `v4.public.` in any result or receipt (RCPT-01, PRXY-06). |
| T-07-LIC | Information disclosure | mock services recorders | high | mitigate | `assertNoLicenseLeak` on both recorders (LIC-05). |
| T-07-COMPLETE | Elevation of privilege | verifyOutcome vs agent | high | mitigate | tools/list has no completion tool; `completed` actor is `verifier` (D-15, Phase 5 D-03). |
| T-07-CLOCK | Tampering | license refresh clamp | high | mitigate | reissue exp never exceeds lease expiry (LIC-03), forced via forceNextExpiresIn + clock advance. |
| T-07-APPROVAL | Spoofing | scripted adapter | medium | mitigate | Adapter only proposes; core owns deny/timeout; unscripted approval folds to deny. |
| T-07-SC | Tampering | npm deps | low | accept | No new package (pre-existing pins). |
</threat_model>
