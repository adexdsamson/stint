<objective>
Add the two additive shared seams every later plan's hybrid wiring depends on, without touching any existing shipped contract: (1) a vitest-free `@stint/core/license-issuer` subpath exposing `createReferenceLicenseIssuer` (a PASETO signer the mock publisher wraps) and `createLicenseIssuerClient` (a runtime-side client that verifies-then-mints a `HeldLicense` over an injected HTTP transport and enforces the LIC-03 clamp), and (2) an additive `@stint/proxy/testing` `forceNextExpiresIn` seam so a test can force a real OAuth vault refresh without advancing the injected clock (D-14, D-05, D-07).

Purpose: There is no production path that turns a token received from a remote publisher into a `HeldLicense` (`mintHeldLicense` is not exported), and `@stint/core/testing`'s mock issuer drags `vitest` into any runtime that imports it (Pitfall 5). The e2e also needs to force a short access-token lifetime to exercise the vault's single-flight refresh (PRXY-08, LIFE-05) deterministically.
Output: The core subpath (with export mechanics), the reference issuer + client with tests, and the proxy testing `forceNextExpiresIn` seam with a test.
</objective>
