<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI -> authorization server | vault refresh/revoke over http requires the loopback relaxation |
| CLI -> publisher | issue/invalidate calls carry no secret; the license token returned must be verified before trust |
| `--publisher` file -> store | persisted binding is non-secret config read later by revoke/cleanup |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-INSECURE | Information disclosure | allowInsecureRequests derivation | high | mitigate | `isLoopbackHttp` allows the flag only for loopback http; non-loopback http stays refused (mandatory negative test). |
| T-07-PASETO | Spoofing | create issue-once guard | high | mitigate | createLicenseIssuerClient verifies the issued token (implicit assertion binds lease id) before treating activation as guarded; unverifiable -> activation_failed, fixed message. |
| T-07-INVLIE | Repudiation | invalidate_license honesty | high | mitigate | Real license collaborator makes `invalidate_license` reflect an actual publisher call (Pitfall 4); delegated stays `not_applicable`. |
| T-07-TOKENLOG | Information disclosure | create/teardown error paths | medium | mitigate | All publisher/AS failures map to fixed-text CliError; no token/upstream text echoed. |
| T-07-BINDURL | Tampering | publisher binding URLs | medium | mitigate | Binding URLs validated https-or-loopback (mirrors manifest CleanupHook.url); malformed file -> fixed usage error. |
| T-07-SC | Tampering | npm deps | low | accept | No new package (pre-existing pins; RESEARCH audit). |
</threat_model>
