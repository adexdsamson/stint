## Build and resolution model (decided here, rated reversible)

- Every package is ESM (`"type": "module"`) with `exports["."] = { "types": "./dist/index.d.ts", "import": "./dist/index.js" }`, built by tsdown (`dts: true`, `format: "esm"`, `platform: "node"`).
- Cross-package imports resolve through `dist/`, so the root `test` script is `pnpm build && vitest run` and CI runs `pnpm build` before `pnpm typecheck` and `pnpm lint`.
- `tsc -b` type-checks through composite project references. Each package tsconfig: `composite: true`, `rootDir: "."`, `include: ["src", "test"]`, `emitDeclarationOnly: true`, `outDir: ".tsc"` (gitignored), so tsc output never collides with tsdown's `dist/`.
- Dependency graph (D-26): spec has no workspace deps; core depends on spec; proxy depends on core and spec; cli depends on core and proxy.
