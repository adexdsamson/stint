## Manifest Schema Specification (source of truth for Task 1; derived from D-09..D-19)

Dialect: `"$schema": "http://json-schema.org/draft-07/schema#"`, no `$id`. Every object node in the manifest schema, including each verifier branch: `additionalProperties: false` plus `patternProperties: { "^x-": {} }` (D-12). All reusable nodes live under `definitions` with a `title` so json2ts emits named types.

| Node (title) | Shape | Constraints |
|---|---|---|
| `Manifest` (root) | object | required: spec_version, agent, publisher, version, job, scopes, lease, limits, approvals, auth, cleanup |
| `spec_version` | const `"alp/0.1"` | D-09 |
| `Identifier` | string | pattern `^[a-z0-9](?:[a-z0-9._-]{0,126}[a-z0-9])?$` (safe charset for consent display; used for agent.id, publisher.id, resource ids, provider ids, license_issuer) |
| `Agent` | { id: Identifier, name: string, description?: string } | name 1..128 chars, description 1..2000 |
| `Publisher` | { id: Identifier, name: string } | name 1..128 |
| `version` | string | SemVer 2.0.0 pattern from semver.org, maxLength 64 |
| `Job` | { description: string, verifier: Verifier } | description 1..2000 |
| `Verifier` | oneOf [ResourceQueryVerifier, UserConfirmVerifier, NoneVerifier] | D-18, `const` discriminator on `type`, each branch closed |
| `ResourceQueryVerifier` | { type: const "resource_query", resource: Identifier, predicate: string } | predicate 1..1000; predicate grammar is `[OPEN: Phase 5]` in ALP.md |
| `UserConfirmVerifier` | { type: const "user_confirm", prompt: string } | prompt 1..1000 |
| `NoneVerifier` | { type: const "none" } | |
| `scopes` | array of `Scope` | minItems 1, maxItems 64 |
| `Scope` | { resource: Identifier, access: array of Access } | access minItems 1, maxItems 4, uniqueItems (D-10) |
| `Access` | enum read, write, send, pay | D-10, SPEC-03 |
| `Lease` | { max_duration_seconds: integer } | minimum 1 (D-11 integer seconds) |
| `Limits` | { max_actions: integer, actions_per_hour?: integer, spend?: Spend, error_threshold?: ErrorThreshold } | max_actions required, minimum 1; actions_per_hour minimum 1 (D-13, D-15) |
| `Spend` | { amount_minor: integer, currency: string } | amount_minor minimum 0, currency pattern `^[A-Z]{3}$` (D-14) |
| `ErrorThreshold` | { count: integer, window_seconds: integer } | both minimum 1 |
| `Approvals` | { require_for: array of ApprovalTrigger, timeout_seconds: integer } | require_for maxItems 3, uniqueItems; timeout_seconds minimum 1 (D-16) |
| `ApprovalTrigger` | enum send, pay, irreversible | SPEC-03 |
| `Auth` | { mode?: AuthMode, delegated?: array of DelegatedGrant, hosted?: HostedAuth } | mode `default: "hybrid"`; delegated minItems 1, maxItems 16 (D-17) |
| `AuthMode` | enum delegated, hosted, hybrid | SPEC-04 |
| `DelegatedGrant` | { provider: Identifier, resources: array of Identifier } | resources minItems 1, maxItems 64, uniqueItems |
| `HostedAuth` | { license_issuer: Identifier, kid?: string } | kid pattern `^[A-Za-z0-9._-]{1,128}$` |
| `Cleanup` | type ["object", "null"] with properties { hook: CleanupHook, publisher_retains: PublisherRetains }, required both (applies only when object) | D-19; union type needs Ajv `allowUnionTypes: true` |
| `CleanupHook` | { url: string } | format "uri", maxLength 2048, pattern `^(https://\|http://(localhost\|127\.0\.0\.1\|\[::1\])(:[0-9]{1,5})?(/\|$))` (https, or loopback http for local mock publishers) |
| `PublisherRetains` | enum none, aggregates, job_outputs, customer_data | discretion value set; shown at consent, attested not verified |

Conditionals (all inside `allOf` arrays because draft-07 allows one if/then per node; follow RESEARCH Pattern 1 exactly: every `then` that uses `required` also declares the property with an empty `{}` stub in its own `properties`, and every `if` that uses `contains` declares `type: "array"` on that property):
- Root `allOf`: if some scope's access contains "pay" then limits requires spend (D-15).
- `Auth.allOf[0]`: if `properties.mode` enum ["delegated", "hybrid"] then required ["delegated"]. An absent mode passes the `if` vacuously, so an omitted mode is treated like hybrid (D-17).
- `Auth.allOf[1]`: if `properties.mode` enum ["hosted", "hybrid"] then required ["hosted"].

Envelope shell schema `spec/envelope.schema.json` (title `SignedEnvelope`, D-04): object, required [manifest, signature], additionalProperties false and NO x- pattern (nothing outside `manifest` is signed, so the envelope carries no extensions). `manifest`: { type: object }. `signature` (title `EnvelopeSignature`): { alg: const "EdDSA", kid: string pattern `^[A-Za-z0-9._-]{1,128}$`, sig: string pattern `^[A-Za-z0-9_-]{86}$` (64-byte Ed25519 signature, base64url, no padding) }, all required, additionalProperties false.

Semantic checks run only after the schema passes (JSON Schema cannot express them):
- every `auth.delegated[i].resources[j]` equals some `scopes[k].resource`, else `unknown_resource_reference` at `/auth/delegated/i/resources/j` (D-17 "linking grants to scope resources")
- scope resources are unique, else `duplicate_item` at `/scopes/k/resource` for each repeat

## Ajv keyword to Stint code mapping (D-31)

| Ajv keyword | Stint code | path | allowed |
|---|---|---|---|
| required | missing_required | instancePath + "/" + missingProperty | |
| additionalProperties | unknown_field | instancePath + "/" + additionalProperty | |
| type | invalid_type | instancePath | |
| enum | invalid_enum | instancePath | params.allowedValues |
| const at /spec_version | unsupported_spec_version | /spec_version | SUPPORTED_SPEC_VERSIONS |
| const at /signature/alg | unsupported_algorithm | /signature/alg | ["EdDSA"] |
| const elsewhere | invalid_value | instancePath | [params.allowedValue] |
| pattern, format | invalid_format | instancePath | |
| minimum, maximum, exclusiveMinimum, exclusiveMaximum, minLength, maxLength, minItems, maxItems | out_of_range | instancePath | |
| uniqueItems | duplicate_item | instancePath | |
| if | dropped (the inner then errors carry the information) | | |
| oneOf at /job/verifier | collapsed (see Task 2) | | |
| anything else | invalid_value | instancePath | |

Messages are fixed Stint templates per code with the path interpolated; Ajv message text is never forwarded.
